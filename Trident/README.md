尽量不要修改预制体的名称，FX 层的动画有 VRC Animator Play Audio 的 Audio Source 与预制体名称相关联
安装步骤：
1. 将预制体 Trident 拖入 Avatar
2. 先打开 Container 与 Kinematic Rigidbody 方便调整位置，选中 Rigidbody Launcher Target，将 Head 拖入 Source Transform，取消勾选 Is Active，位置调整完毕后，点击 Activate 按钮，隐藏 Container 与 Kinematic Rigidbody。
3. 选中 Look At 对象，将 Head 拖入 Source Transform
